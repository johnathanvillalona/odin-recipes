# odin-recipes
Classic recipes website

What is the project?:
This is a simple website for recipes which consists of a home page and 3 recipe pages.
Each recipe page includes a title, image, description, ingredients, and steps to create the dish.


What skills does this demonstrate?:
This project demonstrates knowledge on setting up HTML documents, project file structure, using basic HTML syntax to display information and images, as well as link to other pages.
-HTML basic syntax
-Heading tags
-<img> and <a>
